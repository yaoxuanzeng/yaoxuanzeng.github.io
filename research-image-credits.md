# Research imagery

- **Enceladus** (`research-enceladus.jpg`): NASA/JPL-Caltech/Space Science Institute. Source: https://science.nasa.gov/resource/saturns-moon-enceladus-poster-version-a/ . User supplied image; displayed without raster edits.
- **Jupiter / Exotic Marble** (`research-jupiter.webp`): Image data NASA/JPL-Caltech/SwRI/MSSS; image processing Prateek Sarpal, © CC NC SA (credit as stated by NASA). Source: https://science.nasa.gov/image-detail/jupiter-exotic-marble/ . Enhanced color; south up. User supplied image; displayed without raster edits. This attribution and the source notice must remain with the image.
- **TRAPPIST-1** (`research-trappist-1.jpeg`): NASA/JPL-Caltech. Source: https://www.jpl.nasa.gov/images/pia21424-the-trappist-1-habitable-zone/ . Artist illustration; planetary appearances are hypothetical. User supplied image; displayed without raster edits.
- **Icy moon ocean process schematic** (`research-icy-ocean-processes.png`): supplied by Yaoxuan Zeng as Sketch_New_3D_Vertical.pdf, rendered to PNG for the web. The conceptual diagram includes convection, baroclinic eddies, and tides; it is an overview of ocean processes.
- **Video poster frames** (`research-jets-poster.png`, `research-ocean-poster.png`): extracted at 2 seconds from the repository’s existing U_animation.mp4 and ocean_surface_zonal_velocity.mp4. The original animations are unchanged.
